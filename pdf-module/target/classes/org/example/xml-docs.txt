Intro:
> Helps in data transfer between two devices.
XML stands for eXtensible Markup Language
XML is a markup language much like HTML
XML was designed to store and transport data
XML was designed to be self-descriptive
XML is a W3C Recommendation

How to use XML:
> XML does not do anything. It was created to structure, store, and transport information.
XML does not carry any information about how to be displayed.
The same XML data can be used in many different presentation scenarios.
Because of this, with XML, there is a full separation between data and presentation.

example:

<?xml version="1.0" encoding="UTF-8"?>
<bookstore>

XML tree structure:

XML documents are formed as element trees.
An XML tree starts at a root element and branches from the root to child elements.
All elements can have sub elements (child elements):

<?xml version="1.0" encoding="UTF-8"?> -----------> this is prolog in xml (The XML prolog is optional. If it exists, it must come first in the document.)

e.g.:
<root>
  <child>
    <subchild>.....</subchild>
  </child>
</root>


XML syntax, elements, attributes, and comments:

All XML Elements Must Have a Closing Tag.
XML tags are case sensitive.
In XML, the attribute values must always be quoted.
In XML, comments are defined as <!-- comment goes here -->.
